# 推荐报告固定规则

## 内容权威与允许转换

- PDF 是文字权威来源。不得改写、润色、总结、压缩或补造原文。
- 只允许统一日期标点、移除 PDF 的可见编号，并把编号转换为 Word 真实项目符号。
- 跨页断句必须依据 PDF 前后页合并，不能丢字或重复。

## 第一页

- 保持母版的 CONNECTUS 标识、标题、布局、保密声明和首页页眉页脚。
- 替换中文姓名、性别、年龄、婚姻状态、目前工作地、候选人和推荐职位。
- 客户未提供时只保留“客户：”。
- 顾问、手机、电话和邮箱未提供时只保留标签。
- 婚姻状态和求职动机没有来源时留空。
- 推荐理由使用 PDF 的“优势亮点”或“自我评价”原文，并使用 Word 真实项目符号。
- 推荐职位未指定时使用当前职位；存在多个合理答案时询问用户。
- 当前工作城市优先使用 PDF 明确字段；可由当前工作地点可靠确定时使用该城市，否则询问用户。

## 第二页及以后

- 第二页从“学历”开始，随后为“职业经验”。
- 教育经历使用日期、学校、学历、专业。
- 工作经历按 PDF 顺序排列。
- 日期在左；公司、职位和工作地点在右。
- 地点标签必须统一为“工作地点：”，禁止使用“地点：”。
- 每段经历使用“工作描述：”，其下每个原文工作项使用 Word 真实项目符号。
- 带小标题的工作项在同一个项目符号段落中保留小标题和正文，用换行分隔，不添加冒号。
- 时间、公司、职位、工作地点和“工作描述：”标签不得使用项目符号。
- 时间、公司、职位、工作地点和“工作描述：”标签不得设置 `keepNext`、`keepLines` 或 `pageBreakBefore`。这些属性会在显示格式标记时产生黑色段落控制点。
- 工作描述项目符号也清除上述分页控制属性，只保留真实项目符号。
- 默认不显示行业类别、企业性质和公司规模。
- 默认不加入项目经历、证书、语言能力和附加信息；用户明确要求时才加入原文。

## 版式与结构

- 保留一个节、A4 页面、原页边距和“首页不同”设置。
- 保留第二页以后的蓝色页眉、橙色线条和地址页脚。
- 复用母版字体、字号、颜色、缩进、行距和制表位。
- 不输入可见的 `1.`、`2.` 等文本编号。
- 允许工作描述跨页，但不得出现裁切、页眉页脚遮挡或无意义空白页。

## 残留禁止项

生成结果中不得残留未被当前 PDF 支持的母版文字，包括但不限于：

- 王威、客服管理。
- 北京华御鲁采餐饮有限公司、北京富国大通基金销售有限公司。
- “组建华东区域销售团队。”
- “筹建经历：具备从0到1筹建银保监会认可机构的经验……”

若这些文字本身确实出现在当前候选人 PDF 中，则视为合法原文，不按残留处理。
